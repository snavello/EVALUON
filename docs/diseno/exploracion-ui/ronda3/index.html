EVALUON · Ronda 3

Cinco versiones sobre la base de Jacarandá, en negro, grises y blanco con verde lima para resaltar. Los gráficos usan colores levemente apagados. Cada sección abre con un tablero de información agregada y cada mosaico lleva a su detalle. Las versiones cambian qué datos van al tablero, cómo se abre el detalle, la letra y la foto.

  • Clic en un mosaico: abre el detalle
  • [ ] versión anterior o siguiente
  • T otra transición entre pestañas
  • ← → pestañas
  • G volver acá

Para 8000: todo se arma con las plantillas actuales, CSS propio y muy poco JavaScript. Los gráficos son SVG generados en la plantilla. El cajón y la ventana modal usan el elemento nativo de diálogo del navegador. El pase entre secciones se hace con transiciones entre páginas declaradas en CSS, en Edge y Chrome actuales. Las tipografías se alojarían en el equipo.
