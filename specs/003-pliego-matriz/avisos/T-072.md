# Avisos para T-072

## De la verificación de T-067 (2026-10-03)

- La base no hace valer que `tenders_reading` y `tenders_segment` "no se modifican" (plan, "Modelo de datos"): un `UPDATE tenders_segment SET text = ...` se acepta. Solo `tenders_run_step`, `tenders_requirement_change` y el contenido de una versión validada tienen triggers. Las funciones de carga y lectura no deben modificar una lectura ni sus tramos después de crearlos; si hace falta leer de nuevo, se crea otra lectura con `sequence` siguiente (única por documento).
- `Segment.text` debe ser igual a `canonical_text[char_start:char_end]`. La base solo comprueba `char_end >= char_start`; la igualdad es responsabilidad del código que crea los tramos.

- (Coordinador, 2026-10-03) Hay dos casos más en `corpus/casos/caso-01/` y `caso-02/` (fuera del repositorio). **Están reservados para la aceptación**: no correr el sistema sobre ellos ni usarlos para ajustar o probar a mano. Para pruebas manuales, solo el caso-00. El caso-01 trae 2 circulares reales (REQ-031) y 52 páginas (tiempo de un pliego de unas 50).
