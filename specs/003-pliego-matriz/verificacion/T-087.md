## Avisos

- El reloj se fija reemplazando `datetime` dentro de `django.utils.timezone`: solo afecta a `timezone.now()` y lo que depende de él. Un código que llame a `datetime.now()` directamente no lo ve. Si otro test necesita fijar el reloj, conviene llevar el fixture a `tests/conftest.py` o usar `time_machine`.
- El test representa la hora argentina como UTC-3 fijo, no con `America/Argentina/Buenos_Aires`. Si volviera el horario de verano, habría que revisar los instantes.
