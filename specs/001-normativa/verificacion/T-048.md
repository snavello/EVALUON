## Avisos para tareas siguientes

- (T-049, runbook) El comando de respaldo del plan (`docker compose exec db pg_dump -Fc evaluon`) no sirve tal cual: falta `-T`, sin el cual la terminal puede alterar la salida binaria en Git Bash, y falta `-U`, sin el cual se conecta como `root`. Usar el de `scripts/migrate_on_start.sh`.
- (T-049, runbook) Restaurar siempre en una base nueva. Restaurar sobre `evaluon` es destructivo y pide confirmación.
- (Despliegue) Si se separa el usuario de la aplicación del dueño del esquema, `pg_restore` necesita un superusuario o el dueño para crear `vector` y `unaccent`.
- Cuando hay una migración pendiente, `migrate --check` no dice cuál es: `showmigrations` la muestra.
